# Student Certificate Service 🎓

Полноценная система заказа студенческих справок, построенная на базе микросервисной архитектуры с асинхронной обработкой.

## Стек технологий

*   **Бэкенд & Воркер:** Go 1.25, Clean Architecture
*   **База данных:** PostgreSQL 15 (с автомиграциями при старте)
*   **Брокер сообщений:** RabbitMQ
*   **Фронтенд:** Vanilla JavaScript, HTML, CSS (Glassmorphism UI)
*   **Мониторинг:** Prometheus, Grafana
*   **Инфраструктура:** Docker, Docker Compose, Nginx

## Структура проекта

Проект разделен на несколько независимых компонентов:

1.  **Backend (`/backend`)**: Основной HTTP API сервис. Реализован по принципам Clean Architecture (Handlers -> UseCases -> Repository). Отвечает за:
    *   Регистрацию и авторизацию (JWT).
    *   Прием заявок на справки и сохранение их в PostgreSQL со статусом `pending`.
    *   Публикацию событий о новых заявках в очередь RabbitMQ (`cert_requests`).
    *   Выдачу списка справок пользователя.
2.  **Worker (`/worker`)**: Асинхронный фоновый сервис. Подключается к RabbitMQ, забирает задачи из очереди, имитирует долгую генерацию справки (5 секунд) и обновляет статус справки в базе данных на `ready`.
3.  **Frontend (`/frontend`)**: Легковесное Single Page Application (SPA), общающееся с нашим REST API. Раздается через Nginx.
4.  **Load Tester (`/loadtester`)**: Вспомогательный Go-скрипт, который в бесконечном цикле генерирует запросы (регистрация/логин) для создания нагрузки, чтобы мы могли наблюдать за графиками в Grafana.

## Как запустить

Вам потребуется только установленный **Docker** и **Docker Compose**.

1. Перейдите в папку с проектом:
   ```bash
   cd /Users/anafinov/.gemini/antigravity/scratch/student-cert-service
   ```

2. Запустите все сервисы одной командой:
   ```bash
   docker-compose up -d --build
   ```
   *Первый запуск может занять пару минут, так как скачиваются образы БД, RabbitMQ и собираются Go-сервисы.*

3. Для остановки проекта используйте:
   ```bash
   docker-compose down
   ```

## API Эндпоинты

| Метод | Эндпоинт     | Описание | Auth Required |
| :--- | :--- | :--- | :--- |
| `POST` | `/register` | Регистрация нового студента | ❌ |

| `GET`  | `/requests` | Получить список своих справок | ✅ |

## Особенности реализации

*   **Graceful Shutdown**: Бэкенд корректно завершает работу, дожидаясь обработки текущих HTTP-запросов перед выключением.
*   **Безопасность**: Пароли хэшируются с помощью `bcrypt`. CORS настроен корректно. Авторизация работает через `Bearer JWT`.
*   **Производительность**: Минимальный размер Docker-образов (используются `alpine` и многоэтапные сборки). Go-сервисы весят всего по несколько мегабайт.
